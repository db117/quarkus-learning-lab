# 01. Spring 开发者眼中的 Quarkus

## 学习目标

建立 Quarkus 的第一性认知：它不是“另一个 Spring Boot”，而是一个 **尽可能把框架工作提前到构建期完成** 的 Java 框架。

## Spring 对照

| Spring                 | Quarkus                                      |
|------------------------|----------------------------------------------|
| ApplicationContext     | ArC / CDI Container                          |
| BeanDefinition         | BeanInfo / build-time metadata               |
| BeanPostProcessor      | BuildStep / generated code / CDI interceptor |
| AutoConfiguration      | Extension                                    |
| Runtime classpath scan | Jandex + build-time processing               |
| Runtime proxy          | build-time generated bytecode（大量场景）    |
| Spring MVC             | Quarkus REST                                 |
| Reactor                | Mutiny                                       |
| Spring AOT             | Quarkus 从架构上就强调 build time            |

## 必做实验

1. 创建空 Quarkus 应用。
2. 分别执行 dev、test、package。
3. 查看 `target/quarkus-app`。
4. 记录 JVM 启动过程和开发模式启动过程的区别。
