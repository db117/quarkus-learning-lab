# 18. Recorder：把构建期结果带到运行期

## 学习目标

理解 Quarkus 的 build-time / runtime 边界。

## 学习模型

```text
BuildStep
   ↓
分析 metadata
   ↓
Recorder 调用
   ↓
记录为 generated bytecode
   ↓
Static Init / Runtime Init
   ↓
真实 runtime 调用
```

## 核心问题

1. 为什么不直接在 BuildStep 中调用 runtime 对象？
2. Recorder 到底“记录”的是什么？
3. Static Init 与 Runtime Init 有什么区别？
4. 哪些配置必须等到 runtime 才能读取？

## 必做实验

让 Extension 在 runtime 初始化一个 `LearningRegistry`，数据来源于 build-time 的 Jandex 扫描结果。

## 文档产出

《Quarkus Recorder：Build Time 如何连接 Runtime》
