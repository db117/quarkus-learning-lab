# 02. 第一个 Quarkus 应用

## 学习目标

熟悉 Quarkus CLI / Maven Plugin、Dev Mode、项目目录和 Extension 依赖管理。

## 实践内容

- 创建项目
- `quarkus dev`
- Dev UI
- Live Reload
- 增删 Extension
- JVM package
- 查看生成目录

## Spring 对照

```text
spring-boot-maven-plugin
spring-boot:run
DevTools
Starter
```

对比：

```text
quarkus-maven-plugin
quarkus:dev
Dev Mode
Extension
```

## 必做实验

修改一个 REST 端点，不重启应用观察 Live Reload。

## 文档产出

《Quarkus 项目结构与开发模式》

## 完成标准

能够解释普通依赖与 Quarkus Extension 的差别，并能独立创建、运行、打包项目。
