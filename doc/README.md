# Spring 开发者的 Quarkus 源码学习路线

这是一套面向 **精通 Spring / Spring Boot 的 Java 开发者** 的 Quarkus 学习路线。

目标不是“学会几个 Quarkus 注解”，而是借助已有的 Spring 源码知识，真正理解 Quarkus 的核心架构：

```text
Spring Runtime Framework                Quarkus Build-time Framework
        │                                       │
ApplicationContext / BeanFactory               ArC / CDI
        │                                       │
BeanPostProcessor                              BuildStep
        │                                       │
Runtime metadata / proxy                      BuildItem DAG
        │                                       │
AutoConfiguration                             Extension
        │                                       │
Runtime proxy                                 Generated bytecode
                                                │
                                  Jandex / Gizmo / Recorder
                                                │
                                         Native Image
```

> 本路线有意移除了 Hibernate / Panache。学习项目不依赖 ORM，把精力集中在 Quarkus 本身。

## 推荐环境

- JDK 21
- Maven
- Quarkus 3.x 当前稳定版本
- IntelliJ IDEA
- GraalVM（Native Image 阶段再安装）
- Git

## 每章统一学习模板

每完成一章，都按下面结构整理到你自己的网站：

1. 这个机制解决什么问题
2. Quarkus 基本使用
3. Spring 中对应什么
4. Spring 实现原理（尽量链接已有笔记）
5. Quarkus 实现原理
6. 源码入口
7. 核心调用链
8. Spring vs Quarkus 流程图
9. 为什么 Quarkus 这样设计
10. 总结

不要把源码笔记写成单纯的 `A -> B -> C` 调用链。每篇至少回答一个“为什么”。

## 使用方式

建议严格按编号执行。每一章都必须完成：

- 示例代码
- Debug / Source Trace
- 一张流程图
- 一篇 Markdown 笔记
- 章节中的完成标准

完成后再进入下一章。
